Usage: codeintel build assets [ARGS]

List materialized assets for the current snapshot.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ ASSET --asset         Filter to a specific asset key (e.g.,                  │
│                       analytics.function_metrics). [env var:                 │
│                       CODEINTEL_BUILD_ASSETS_ASSET] [default: (none)]        │
│ TARGET --target -t    Filter to assets produced by a specific target. [env   │
│                       var: CODEINTEL_BUILD_ASSETS_TARGET] [default: (none)]  │
│ VERSIONS --versions   Include asset versions from the Phase 4 catalog. [env  │
│                       var: CODEINTEL_BUILD_ASSETS_VERSIONS] [default: false] │
│ TYPE --type           Filter by asset type: table, view, or artifact. [env   │
│                       var: CODEINTEL_BUILD_ASSETS_TYPE] [default: (none)]    │
│ FORMAT --format -f    Output format: table (default), json, or csv. [env     │
│                       var: CODEINTEL_BUILD_ASSETS_FORMAT] [default: table]   │
│ --flags               [env var: CODEINTEL_BUILD_ASSETS_FLAGS] [default:      │
│                       --flags]                                               │
│ ROOT --root -r        Explicit project root directory. [env var:             │
│                       CODEINTEL_BUILD_ASSETS_ROOT] [default: (none)]         │
│ OUTPUT-FORMAT         Output format. [choices: text, json, jsonl] [env var:  │
│   --output-format     CODEINTEL_BUILD_ASSETS_OUTPUT_FORMAT] [default: text]  │
│ JSON --json           Alias for --output-format json. [env var:              │
│                       CODEINTEL_BUILD_ASSETS_JSON] [default: false]          │
│ VERBOSE --verbose -v  Increase verbosity (0=warnings, 1=info, 2=debug). [env │
│                       var: CODEINTEL_BUILD_ASSETS_VERBOSE] [default: 0]      │
╰──────────────────────────────────────────────────────────────────────────────╯
