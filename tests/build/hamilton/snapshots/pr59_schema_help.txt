Usage: codeintel build schema COMMAND

Schema product commands (compile, diff, migrate, etc.).

╭─ Commands ───────────────────────────────────────────────────────────────────╮
│ compile       Compile a deterministic schema manifest for selected targets.  │
│ diff          Diff a compiled schema manifest against an expected file.      │
│ inferability  Report inferability status for schema outputs.                 │
│ migrate       Update expected manifest to match current schemas.             │
╰──────────────────────────────────────────────────────────────────────────────╯
