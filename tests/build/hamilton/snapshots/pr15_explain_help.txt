Usage: codeintel build explain TARGET [ARGS]

Explain why a target is stale and what dependencies changed.

╭─ Parameters ─────────────────────────────────────────────────────────────────╮
│ *  TARGET --target              Target name to explain (e.g.,                │
│                                 function_metrics). [env var:                 │
│                                 CODEINTEL_BUILD_EXPLAIN_TARGET] [required]   │
│    FORCE --force --empty-force  Mark specific targets as forced              │
│      -f                         (repeatable). [env var:                      │
│                                 CODEINTEL_BUILD_EXPLAIN_FORCE] [default:     │
│                                 (none)]                                      │
│    GRAPH-SOURCE --graph-source  Dependency graph source: hamilton (default)  │
│                                 or targetgraph. [choices: targetgraph,       │
│                                 hamilton] [env var:                          │
│                                 CODEINTEL_BUILD_EXPLAIN_GRAPH_SOURCE]        │
│                                 [default: hamilton]                          │
│    --flags                      [env var: CODEINTEL_BUILD_EXPLAIN_FLAGS]     │
│                                 [default: --flags]                           │
│    ROOT --root -r               Explicit project root directory. [env var:   │
│                                 CODEINTEL_BUILD_EXPLAIN_ROOT] [default:      │
│                                 (none)]                                      │
│    OUTPUT-FORMAT                Output format. [choices: text, json, jsonl]  │
│      --output-format            [env var:                                    │
│                                 CODEINTEL_BUILD_EXPLAIN_OUTPUT_FORMAT]       │
│                                 [default: text]                              │
│    JSON --json                  Alias for --output-format json. [env var:    │
│                                 CODEINTEL_BUILD_EXPLAIN_JSON] [default:      │
│                                 false]                                       │
│    VERBOSE --verbose -v         Increase verbosity (0=warnings, 1=info,      │
│                                 2=debug). [env var:                          │
│                                 CODEINTEL_BUILD_EXPLAIN_VERBOSE] [default:   │
│                                 0]                                           │
╰──────────────────────────────────────────────────────────────────────────────╯
